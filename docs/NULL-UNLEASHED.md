## Actions and scheduling

Observer, Glitch Entrance, Curiosity and Mischief retain their original keyframes. Peek turns and ducks out, Suspicious leans in with a narrowed gaze, Satisfied nods and opens its grin, and Disturbed briefly displaces the existing red fragments before the silhouette settles. The retreat motion follows the action. During a long rest Null stays hidden.

The fictional gamma gag is eligible only in a measured 166 × 84 px hero area. The right hand aims before a single short red shape fades in and out inside the slot. Its visible DE/EN fiction label identifies the effect. Ambient selection chooses it in at most 0.4% of opportunities, with fewer appearances when hero space is unavailable. An eligible context action can advance the ambient timer, but occupancy, edit focus, current pointer interaction, preferences and the cooldown still take priority. The first ambient rest lasts 6–12 s, subsequent ambient rests 13–32 s, and the earliest next visit starts at least 8 s after the previous visit’s planned end.

One WeakMap owner maintains one SVG, one slot and one cancelable timeout. CSS performs the motion. The existing inspect interface reports the stage, pose, phase, pending context and resource counts. Layout work is triggered by visibility, resize, localization, navigation and the scheduler. The manager only observes UI state and consumes its own seeded random stream. Off, Reduced Motion, focus, hidden documents and unavailable space use the existing eligibility policy. Reduced Motion may show a static pose, with no animated effect.

Optional speech bubbles are deferred. The actual observations point toward the lab in a general sense. They use no measured orbit or tracked object coordinates.
